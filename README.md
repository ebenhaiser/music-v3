# Music Web

Website statis untuk menampilkan lagu original dengan pengalaman berkualitas seperti Spotify dan Musixmatch.

## Cara buka

Buka file [index.html](index.html) di browser, atau unggah folder ini ke GitHub Pages.

## Fitur

- Hero section dan katalog lagu
- Bottom player tetap terlihat
- Queue panel
- Lyrics overlay dengan mode chord
- Search dan sorting
- Tema dark/light
